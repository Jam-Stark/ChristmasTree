# 🎄 手势控制圣诞树 3D

一个用手势控制的 3D 圣诞树互动体验。使用 Three.js 和 MediaPipe Hands 构建。

## 🌐 在线体验（推荐！）

直接访问：**https://jam-stark.github.io/ChristmasTree/**

> 无需安装任何软件，打开网址即可使用！

## ✨ 功能特点

- 🎄 由金色球体、绿色方块、红色装饰球和糖果棍组成的精美 3D 圣诞树
- ⭐ 树顶闪烁发光的星星
- 📸 可以展示你自己的照片
- 🖐️ 手势控制：握拳、张开手掌、捏合手指
- ✨ 电影级辉光效果 (Bloom)
- 🌫️ 梦幻的雾气效果

## ️ 操作指南

| 手势 | 效果 |
|------|------|
| ✊ 握拳 | 聚合成圣诞树 |
| 🖐 张开手掌 | 散开成星光粒子 |
| 👌 捏合手指 | 抓取放大照片（散开状态下） |
| 👋 移动手掌 | 旋转视角（散开状态下） |
| ⌨️ 空格键 | 切换圣诞树/散开（备用） |

## � 本地运行（开发者）

如需本地运行或添加自己的照片：

### Mac
双击 `启动圣诞树.command`

### Windows  
双击 `启动圣诞树.bat`

> 需要安装 [Python](https://www.python.org/downloads/)

### 添加照片
1. 将照片放入 `photos` 文件夹
2. 重命名为 `1.jpg`, `2.jpg`, `3.jpg` ...
3. 刷新页面
