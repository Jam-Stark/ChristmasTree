# 🎄 手势控制圣诞树 3D

一个用手势控制的 3D 圣诞树互动体验。使用 Three.js 和 MediaPipe Hands 构建。

![Christmas Tree](https://img.shields.io/badge/Made%20with-❤️-red)

## ✨ 功能特点

- 🎄 由金色球体、绿色方块、红色装饰球和糖果棍组成的精美 3D 圣诞树
- ⭐ 树顶闪烁发光的星星
- 📸 可以展示你自己的照片
- 🖐️ 手势控制：握拳、张开手掌、捏合手指
- ✨ 电影级辉光效果 (Bloom)
- 🌫️ 梦幻的雾气效果
- ☀️ 暖黄色顶光照明

## 🚀 快速启动

### Mac 用户
双击 `启动圣诞树.command`

### Windows 用户
双击 `启动圣诞树.bat`

浏览器会自动打开 `http://localhost:8000`

## 📸 添加你的照片

1. 将照片放入 `photos` 文件夹
2. 重命名为 `1.jpg`, `2.jpg`, `3.jpg` ... （支持最多 13 张）
3. 刷新页面

## 🖐️ 手势控制

| 手势 | 效果 |
|------|------|
| ✊ 握拳 | 聚合成圣诞树 |
| 🖐 张开手掌 | 散开成星光粒子 |
| 👌 捏合手指 | 抓取放大照片（散开状态下） |
| 👋 移动手掌 | 旋转视角（散开状态下） |

## ⌨️ 键盘备用

按 **空格键** 可以在圣诞树和散开状态之间切换（手势识别困难时使用）

## 🛠️ 手动启动（无脚本）

如果启动脚本不工作，可以手动运行：

```bash
cd /path/to/ChristmasTree
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000`

## 📋 系统要求

- 现代浏览器（Chrome、Edge、Firefox）
- 摄像头（用于手势识别）
- Python 3（用于本地服务器）
